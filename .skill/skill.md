Quy định làm việc BẮT BUỘC trong suốt quá trình code:
1. TRƯỚC KHI tạo mới hoặc sửa đổi bất kỳ file/dòng code nào, BẮT BUỘC phải trình bày **Kế hoạch triển khai (Implementation Plan)** chi tiết bao gồm: các file ảnh hưởng, danh sách hàm/logic sẽ thêm/sửa, và luồng dữ liệu.
2. Khi có nhiều phương án xử lý (giao diện, cấu trúc dữ liệu, thuật toán), BẮT BUỘC phải đưa ra tối thiểu **2 - 3 lựa chọn kèm ưu/nhược điểm** và chờ tôi xác nhận mới tiến hành viết code.
3. Cấu trúc thư mục phải tuân thủ nghiêm ngặt:
   ├── css/ (style.css, glass.css, variables.css)
   ├── js/ (app.js, storage.js, calculator.js, chart.js)
   ├── image/ (assets, icons)
   └── Page/ (các trang con nếu có)
4. Code phải viết modular, sạch sẽ, tối ưu DOM, xử lý sự kiện mượt mà (map, filter, reduce), tuyệt đối không để lỗi console log.
